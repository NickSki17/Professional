# Selected Engineering Projects

A selection of mechanical design, robotics, computational engineering, simulation, and manufacturing projects demonstrating experience in CAD, optimization, FEA, controls, fabrication, and physical validation.

## Four-Bar EV Charging Arm

Designed and prototyped a four-bar robotic mechanism for automated EV charging-position alignment. Developed a kinematic model and constrained optimization workflow to determine linkage geometry and reduce actuator torque requirements, then implemented the mechanism with Arduino-based servo control and validated the design through physical prototyping.

**Technical focus:** Four-bar kinematics, kinematic synthesis, path generation, constrained optimization, actuator torque minimization, MATLAB, CAD, Arduino control, physical prototyping

[View repository →](https://github.com/NickSki17/Four-Bar-EV-Charging-Arm)

## Hexapod Robot

Designed and built a six-legged robotic platform using servo-actuated legs and an open-loop tripod gait. The mechanical system integrates linkage-based leg mechanisms, CAD, electronics, fabrication, and embedded control. Physical testing demonstrated a maximum forward speed of approximately **0.24 m/s (1.3 body lengths/s)**.

**Technical focus:** Leg mechanism design, tripod gait generation, servo actuation, open-loop control, Arduino, CAD, fabrication, physical testing

[View repository →](https://github.com/NickSki17/Hexapod-Robot)

## Sustainable Chair

Designed a lightweight interlocking foam-core chair around material efficiency, structural load paths, and manufacturability. Evaluated the design using CAD-based structural analysis and validated the physical prototype through static load testing to **103 kg**.

**Technical focus:** Structural design, FEA, load-path analysis, lightweight structures, interlocking assemblies, laser fabrication, physical validation

[View repository →](https://github.com/NickSki17/Sustainable-Chair)
